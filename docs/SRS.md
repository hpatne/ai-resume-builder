# Software Requirements Specification (SRS)

> **Status: To be completed in Phase 2.**

Planned contents (IEEE 830 style):
1. Introduction: purpose, scope, definitions, references
2. Overall description: product perspective, user classes (job seeker, admin), operating environment, constraints
3. Functional requirements: authentication, resume CRUD, company/role customisation, AI generation, ATS checker, admin management
4. Non-functional requirements: security, performance, usability, accessibility, availability
5. External interfaces: UI (see Phase 1 screens in `screenshots/`), REST API, AI service

Phase 1 inputs already available: the problem definition and objectives in the [README](../README.md), the
[reference research](REFERENCE_RESEARCH.md) and the implemented UI flows ([CODE_GUIDE.md](CODE_GUIDE.md)).
